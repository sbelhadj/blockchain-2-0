# Lab 1 captured outputs

Captured 11 October 2026 with Hardhat 3.18.1, solc 0.8.34, OpenZeppelin 5.6.1 and ethers 6.17.0,
on local Hardhat networks (in-process, or a local node where a file name ends in -local).
Ignition progress lines repeated by the terminal were removed (awk '!seen[$0]++') and the
rocket emoji in Ignition's banner was stripped. deploy-gas-local.txt is the gasUsed of block 1
on the same fresh node, which holds only the Ignition deployment; register-local.txt is the next
block. Sepolia captures are produced by the reader.
